    Types¶

    cvl_Mat¶

    [source]

    typedef struct {
    int    height;
    int    width;
    int    channels;
    int    depth;
    size_t stride;
    void * data;
} cvl_Mat;

    A unified matrix type for representing images, kernels, or other arbitrary matrix-like structures.

    Rows are stored consecutively, with channels belonging to the same element stored next to one another. The address of row r is: (uint8_t *)mat->data + r * mat->stride.

    The same type represents both images and other matrix data, such as floating-point kernels. For example, an 8-bit image and a 64-bit kernel are both cvl_Mat, distinguished by depth and channels.

    Members

    height Number of rows.
    width Number of columns.
    channels Number of channels per element. For example, an RGB image has three channels.
    depth Data type used to represent each channel. See cvl_depth_t.
    stride Number of bytes from one row to the next.
    data Pointer to the first byte of matrix storage.

    cvl_format_t¶

    [source]

    typedef enum cvl_format_t {
    CVL_FMT_UNKNOWN,
    CVL_FMT_PBM,
    CVL_FMT_PGM,
    CVL_FMT_PPM,
    CVL_FMT_PNG,
    CVL_FMT_JPG,
} cvl_format_t;

    Enumeration of supported image formats.

    Value Extension Description
    CVL_FMT_UNKNOWN - Unknown or unsupported image format.
    CVL_FMT_PBM .pbm Netpbm Portable Bitmap format for binary images.
    CVL_FMT_PGM .pgm Netpbm Portable Graymap format for grayscale images.
    CVL_FMT_PPM .ppm Netpbm Portable Pixmap format for colored images.
    CVL_FMT_PNG .png Portable Network Graphics, supported via stb.
    CVL_FMT_JPG .jpg Joint Photographic Experts Group, supported via stb. JPEG is a redundant verbocity that will not be condoned.

    The PBM, PGM, and PPM formats are supported natively.

    cvl_depth_t¶

    [source]

    typedef enum cvl_depth_t {
    CVL_UINT8,
    CVL_32S,
    CVL_FLOAT32,
    CVL_FLOAT64,
} cvl_depth_t;

    Enumeration of supported data types used to represent each matrix channel.

    See cvl_cvt_depth() for converting between supported depths.

    Value Description
    CVL_UINT8 8-bit unsigned integer (todo: rename: CVL_8U)
    CVL_32S 32-bit signed integer
    CVL_FLOAT32 32-bit floating point
    CVL_FLOAT64 64-bit floating point

    cvl_color_conversion¶

    [source]

    typedef enum cvl_color_conversion {
    CVL_COLOR_NONE,
    CVL_COLOR_RGB2GRAY,
    CVL_COLOR_BGR2GRAY,
    CVL_COLOR_GRAY2RGB,
    CVL_COLOR_GRAY2BGR,
} cvl_color_conversion;

    Enumeration of supported color-space conversions.

    See cvl_cvt_color() for converting between supported color spaces.

    Value Source Channels Destination Channels Description
    CVL_COLOR_NONE — — No color conversion.
    CVL_COLOR_RGB2GRAY 3 1 Converts RGB color to grayscale.
    CVL_COLOR_BGR2GRAY 3 1 Converts BGR color to grayscale.
    CVL_COLOR_GRAY2RGB 1 3 Copies the grayscale value into each RGB channel.
    CVL_COLOR_GRAY2BGR 1 3 Copies the grayscale value into each BGR channel.

    cvl_thresh_type¶

    [source]

    typedef enum cvl_thresh_type {
    CVL_THRESH_BINARY,
    CVL_THRESH_BINARY_INV,
    CVL_THRESH_TRUNC,
    CVL_THRESH_TOZERO,
    CVL_THRESH_TOZERO_INV,
} cvl_thresh_type;

    Enumeration of supported thresholding operations.

    See cvl_threshold() for applying thresholds.

    Mode Operation
    CVL_THRESH_BINARY src > thresh ? maxval : 0
    CVL_THRESH_BINARY_INV src > thresh ? 0 : maxval
    CVL_THRESH_TRUNC src > thresh ? thresh : src
    CVL_THRESH_TOZERO src > thresh ? src : 0
    CVL_THRESH_TOZERO_INV src > thresh ? 0 : src
