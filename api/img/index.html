    cvl_cvt_depth()¶

    [source]

    void cvl_cvt_depth( const cvl_Mat * src,
                    cvl_Mat *       dst,
                    cvl_depth_t     ddepth,
                    double          alpha,
                    double          beta   );

    Converts a matrix to another type with scaling.

    Effectively: dst(x, y) = saturate_cast(α * src(x, y) + β)

    Parameters

    src Input matrix.
    dst Output matrix.
    ddepth Type to convert to.
    alpha Scale factor (1.0 for no change).
    beta Value added to scaled values (0 for no change).

    cvl_convolve_sep()¶

    [source]

    void cvl_convolve_sep( const cvl_Mat * src,
                       cvl_Mat *       dst,
                       cvl_Mat *       kx,
                       cvl_Mat *       ky  );

    Applies a separable linear filter to an image.

    First, every row of src is convolved with the horizontal kernel, then every column of the result is convolved with the vertical kernel.

    Parameters

    src Input matrix.
    dst Output matrix.
    kx Horizontal kernel.
    ky Vertical kernel.
